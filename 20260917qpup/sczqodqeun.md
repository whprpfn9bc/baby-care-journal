# 我院护理部成功举办 第八期“PICC UNA Module I资质认证培训班”

> 更新时间：2026-09-17 (UTC+8)

第八期“PICC UNA Module I

资质认证培训班”

    为提高PICC技术操作水平，加快PICC置管及维护的持续发展，2017年6月29-30日，由护理部举办的第八期“PICC UNA Module I资质认证培训班”在郑州大学第一附属医院河医院区门诊楼16楼会议室顺利举办。开幕式由李秀霞主任护师主持。护理部刘延锦主任、娄小平副主任、李亚南副主任、药学部杜书章副主任出席了开幕式。

开幕式由李秀霞主任护师主持

    开幕式上，刘延锦主任介绍了郑州大学第一附属医院近年来在静脉输液技术、PICC置管等方面取得的成绩及举办此次培训班的重要意义，它不仅为全省护理同仁搭建了一个互相学习、沟通交流的平台，并且推广了输液治疗的新技术、新方法，使更多的护理人员获得国际认证的专科护士资质证书。

    本次培训班共选拔了来自河南省12家医院的38名护理骨干参加培训。授课老师来自郑州大学第一附属医院IV team 小组核心成员。

    药学部副主任杜书章教授的“化学药物治疗方案评估”、血管外科主任宋燕教授的“血管解剖”，深入浅出的讲解了上肢血管及PICC解剖位置，使学员对血管解剖及化疗药物的相关知识有了进一步的了解；肿瘤科张莹主管护师的“PICC术前患者因素的评估及心理辅导”、肿瘤科李爱敏护士长的“非超声下应用塞丁格尔技术置入PICC操作及维护”及李雯护士长的“PICC常见并发症及处理”课程系统的讲解了PICC标准操作及置管、维护流程，并将自身多年的临床实践及丰富的置管经验与全省护理同仁共享。

    学员纷纷表示，通过这样的培训不仅丰富了临床护士相关知识，同时增进了各医院之间的沟通及交流，促进了临床护理的发展，进一步提高了护理质量。

    理论培训结束后，统一对38位学员进行了理论考核，又组织学员观摩了PICC规范置管与维护操作流程，分组进行模拟操作练习后，逐一进行了操作考核。

    经过理论和实践培训的学员，还需在今后3个月内在临床进行PICC置管实践操作15例以上，经考核合格后，颁发由美国护理资质认证学会授权、美国犹他护理学会发放的血管通路PICC资质认证培“PICC UNA Module I资质认证”证书，此证书具有国际通用性，也是国内目前唯一的国际PICC资质认证证书。

背    景

郑州大学第一附属医院于2011年11月成立IV Team,2013年10月成立全国血管通路培训基地，是我省开展PICC置管最早、置管及维护成功率最高的医院，已面向全省及西北地区成功举办八期PICC 资质认证班，培训合格学员210余人。

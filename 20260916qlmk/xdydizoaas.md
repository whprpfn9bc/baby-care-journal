# 【衢医年味】坚守篇|她，连续4年在除夕夜坚守

> 更新时间：2026-09-16 (UTC+8)

对于大多数人来说，

一家人一起过除夕算不上奢望，

然而，对于医护人员来说，

每逢节假日却比往常更忙碌，

和家人团聚的时光也更为短暂。

1月24日晚，衢州市人民医院呼吸与危重症医学科护士王晓玲依然坚守在护理夜班的岗位，查房、诊间护理、询问病情……脚步一直在病房奔忙，这已经是她**连续第四年除夕夜值班**了。

**工作中的王晓玲**

王晓玲2015年参加工作，先后在衢州市人民医院胃肠小儿外科、重症监护室等科室轮转，2018年，她来到呼吸与危重症医学科病区从事护理工作。

呼吸与危重症医学科与其他临床科室不同，每到年底，住院患者都会比往常增加许多，平时，医生护士的工作强度就很大，要是遇上天气寒冷、气温骤变的季节，“刚下火线，又上前线”的经历也很多见。

“别人春节放假，呼吸与危重症医学科反而更忙，无论诊室还是病区，今年也不例外，除夕上半夜轮到我在病区值班，从下午4点半到次日凌晨1点。”王晓玲笑着说，不能陪伴家人有些遗憾，但是已经习惯了。

“有些患者看到我们年资低的护士做护理，会直接拒绝打针，要请高年资护士打才放心。虽然那一瞬间内心会有一丝波澜，但是看到患者健健康康出院，还是很开心的。” 王晓玲说，护理工作就是这样，有苦有乐。

就在前不久，王晓玲和男朋友领了结婚证，这本结婚证也是来之不易。

“前段时间一直在忙三甲复评，和男朋友各忙各的事，连续2个月没见上一面，领证的事情就推迟了。”王晓玲说，男朋友对她的工作十分理解，也很支持，等忙完这阵子就打算摆结婚酒宴。

王晓玲是江山人，因为除夕夜要值班，今年再一次不能回老家过年。她说，“**选择了这一行就是选择了坚守，相比家人，患者更需要我们的陪伴和照顾。**”

医疗战线上的你，

忙忙碌碌又一年，

手术室里，无影灯下，

汗水浸透衣背；

忙碌在诊室，穿梭在病房，

依然义无反顾。

年末岁初，

照顾患者、照顾家人，

照顾好身边的人，

也请别忘记**照顾好自己**！

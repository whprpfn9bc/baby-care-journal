# 口服铁是主流，哪些孕妈妈不得已接受静脉输铁

> 更新时间：2026-09-17 (UTC+8)

孕期要补铁，差不多全覆盖。

孕妈妈们体内铁储备相当于“银行铁储蓄卡”，如果储蓄值比较少，或者仅有一张“铁信用卡”，现有铁储量低和铁需求的急剧增加（胎儿加速生长期每天在35g左右）很大几率就会出现缺铁及缺铁性贫血。

尽管早筛查，甚至孕前开始口服含铁复合维生素，部分孕妈妈们早孕反应过后启动口服铁剂，孕晚期仍然出现贫血情况，经常有一些孕妈妈们采用了输注大剂量静脉铁来纠正贫血。看看下面中招的原因吧：

1. 素食或偏食：植物性食物（大家心目中补铁“明星”菠菜、车厘子等）中的非血红素铁吸收率低（仅2%-20%），而血红素铁（来自红肉、动物肝脏）吸收率更高（15%-35%）。素食孕妇易储备不足。

2. 铁吸收障碍：如胃大部切除术、慢性胃炎或肠道疾病（如乳糜泻）会减少铁的吸收。

3.不能耐受口服补铁药物。

4. 出血高危因素：双胎妊娠、前置胎盘等高危孕妇可能面临产前或产后大出血风险，需提前储备足够的铁。

5.如果启动补铁时机过晚，譬如等到孕晚期贫血后补铁，大多数孕妇没有足够的铁储备来满足妊娠中期和晚期需求的急剧增加。

**Q：****不补不行吗？**

养育胎儿需要大量铁元素，胎儿胎盘生长需要300-350mg，孕妈妈红细胞增加和胎儿红细胞生成需要500mg，分娩可致元素铁丢失约250mg。

贫血可导致母亲疲劳、智力表现下降、哺乳期减少、感染和产后抑郁，并可增加输血的风险。妊娠期母体铁缺乏可能会产生与婴幼儿认知、精神运动发育和功能相关的长期不良健康结果。

**Q：****静脉补铁注意事项**

输注静脉铁可能出现输液反应，需要有经验的医生监管，以缓慢的初始输注速率开始静脉注射铁剂的给药，监测生命体征，输液结束后应继续监测30 ~ 60分钟。

总结：孕期缺铁绝非小事，科学补铁是保障胎儿智力发育和孕妇健康的关键措施。口服补充铁剂是主流，孕前重视铁筛查，开始预防性补铁提高铁储备，结合饮食和监测，可最大限度降低母婴风险。高危人群应尽早评估，选择个体化方案，为母婴安全筑牢防线。
